# Aurora Studio — single-module interface contract

We are building ONE Harness Web UI plugin bundle: `@local/aurora-studio` (bundle row id `aurora-studio`,
bundle dir `C:\Users\SINORAD\Desktop\test\aurora-studio`).

It is a high-freedom UI customization studio:
- **Theme**: accent color, curated palettes, surface translucency, light/dark/system preference.
- **Background**: curated gradient wallpapers / custom image URL / uploaded image, with opacity, dim, blur.
- **Agent desktop pet**: a draggable, animated companion rendered in the frame-wide overlay.
- **Advanced**: live custom CSS, animations toggle, export/import settings JSON.

## Globals every fragment may use

Provided by Lead core / wrapper:

- `React` — React runtime; `h = React.createElement`.
- `PLUGIN_ID` (`'@local/aurora-studio'`), `STORAGE_KEY` (`'aurora-studio:settings:v1'`).
- `DEFAULT_SETTINGS` — full default settings object (shape below). Treat as read-only.
- `store` — settings store (API below).
- `useSettings()` — React hook returning the current settings object and re-rendering on change.
- `RUNTIME` — runtime facade, `null` until `apply()` runs (components only render after apply).
  - `RUNTIME.getLocale()` → `'zh' | 'en'` (already normalized, use it for all localized text).
  - `RUNTIME.subscribeLocale(fn)` → unsubscribe.
  - `RUNTIME.getScheme()` → `'light' | 'dark'` (the ACTIVE resolved scheme).
  - `RUNTIME.subscribeTheme(fn)` → unsubscribe.
  - `RUNTIME.getPreference()` → `'light' | 'dark' | 'system'`.
  - `RUNTIME.setPreference(id)` → switch the built-in theme preference.
  - `RUNTIME.getThemeService()` → the raw client `theme` service or undefined.
- `THEME_PRESETS` — array of `{ id, name: { zh, en }, accent: '#rrggbb', bg: { light, dark }, schemeHint }`.
  Use `THEME_PRESETS` / `themePresetById(id)` for previews and selection.
- `BACKGROUND_PRESETS` — array of `{ id, name: { zh, en }, css: { light, dark }, animated }`.
  `css[scheme]` is a ready-to-use CSS `background-image` value (gradients). `backgroundPresetById(id)`.
- `BACKGROUND_PRESET_IDS`, `THEME_PRESET_IDS`.
- Color helpers: `isHexColor(s)`, `normalizeHex(s)`, `hexToRgb(s)`, `mixColor(a, b, t)` (both `#rrggbb`,
  returns `#rrggbb`), `withAlpha(hex, alpha)` (returns `rgba(...)`).

## Settings shape (exact field names — UI must write these)

```js
{
  version: 1,
  theme: {
    preset: 'aurora',        // THEME_PRESETS id, or 'custom'
    accent: '#7c6cf6',       // #rrggbb
    surfaceOpacity: 0.9,     // 0.55 .. 1   (1 = opaque surfaces, no wallpaper show-through)
    tint: true,              // tint surfaces with the accent color
  },
  background: {
    enabled: true,
    preset: 'aurora',        // BACKGROUND_PRESETS id, or 'custom'
    imageUrl: '',            // remote http(s) URL, used when preset === 'custom' and imageData is empty
    imageData: '',           // data: URL from an upload (takes priority over imageUrl)
    opacity: 0.85,           // 0.2 .. 1     image/gradient opacity
    dim: 0.45,               // 0 .. 0.8     overlay dim (black in dark mode, white in light mode)
    blur: 14,                // 0 .. 30      blur px
    animated: true,          // animate gradient presets (only if advanced.animations)
  },
  pet: {
    enabled: true,
    character: 'ink',        // PET_CHARACTERS id
    size: 96,                // 40 .. 360 px (slider + wheel resize on the pet)
    opacity: 1,              // 0.3 .. 1
    x: null,                 // null = default bottom-right anchor; otherwise left px
    y: null,                 // null = default anchor; otherwise top px
    mode: 'roam',            // 'still' | 'roam' (free roam) | 'follow' (cursor)
    roamSpeed: 70,           // 20 .. 180 px/s
    moveToken: 0,            // bump to reseed the free-motion position (reset button)
    idleChatter: true,       // random bubbles while idle
    chatterInterval: 60,     // seconds between idle bubbles, 20 .. 300
    lines: [],               // user custom speech lines (strings)
    name: '墨墨',             // display name shown in the bubble prefix
    account: true,           // wallet pill under the pet (account Remote optional)
  },
  advanced: {
    customCss: '',           // injected live via styles.insert
    animations: true,        // globally disable our CSS animations when false
  },
}
```

`store.set({ pet: { enabled: false } })` deep-merges only the given fields. Arrays are replaced.
Components must never mutate the settings object in place.

## Store API

- `store.get()` → current settings (treat as immutable).
- `store.set(patch)` → deep-merge patch, notify subscribers, persist to localStorage.
- `store.replace(next)` → merge `next` over `DEFAULT_SETTINGS` (used by import / reset), notify, persist.
- `store.reset()` → reset to defaults, notify, persist.
- `store.subscribe(fn)` → unsubscribe.

## Pet fragment contract (`src/40-pet-art.js`, `src/45-pet.js`) — pet-artist

`40-pet-art.js`:
- `const PET_CHARACTERS` — at least 5 original characters:
  `{ id, name: { zh, en }, accent?: boolean }`. Suggested ids: `ink`, `cat`, `ghost`, `robot`, `star`.
- `function petCharacterLabel(id)` — localized name using `RUNTIME.getLocale()`.
- `function PetArt(props)` — pure presentational SVG React component.
  props: `{ character, mood, size, accent, name }`.
  - `mood`: one of `'idle' | 'happy' | 'talk' | 'sleep' | 'drag'` (default `'idle'`).
  - `size`: number px for the square canvas (viewBox `0 0 120 120`).
  - `accent`: `#rrggbb` string used for body tint / ears / accessories (fallback `#7c6cf6`).
  - `name`: used for `aria-label`/`title` only.
  - `<svg>` must be `aria-hidden="true"` when used purely decoratively, or have a readable label in the overlay.
  - Pupils/mouth/tail/antenna must carry `data-part`-free, stable class names under `.aurora-pet-` so CSS
    keyframes can animate blink/bob/talk. No external images, no fonts.
- `const PET_CSS` — string with ALL styles for the pet art and overlay (`.aurora-pet-*` classes and
  `@keyframes aurora-pet-*`). Global pet container styles may be in this string too.
  Colors for artwork may be literal; bubble/chrome colors MUST use `--dsw-alias-*` tokens.
- Export nothing (`export` forbidden) — just declare these top-level symbols.

`45-pet.js`:
- `function PetOverlay()` — React component rendered in the `shell.overlay` slot.
  - Uses `useSettings()`; returns `null` when `!settings.pet.enabled`.
  - Root is `position: fixed; pointer-events: none` full-frame; the pet body itself re-enables
    `pointer-events: auto` and is the only hit target. z-index inside the overlay is fine (let the slot layer own it).
  - Placement: `settings.pet.x/y` are px from the viewport left/top; when `null`, anchor bottom-right
    (e.g. `right: 32px; bottom: 100px`). Clamp into the viewport on mount, on window resize, and on drag end.
  - Dragging: pointer events with `setPointerCapture`; threshold 4px distinguishes click from drag; while
    dragging set mood `'drag'`, persist `x/y` to the store on pointerup only.
  - Interaction: click → bubble with a random line (built-in lines + `settings.pet.lines`); double click →
    `'happy'` animation + a line; bubble auto-hides after ~4s. Bubble shows `settings.pet.name` as prefix.
  - Idle: random bubbles every `chatterInterval` seconds (jitter ±30%) when `idleChatter` is on and the
    document is visible; clear all timers in cleanup; no chatter while dragging.
  - Eye tracking: listen to `window` pointermove and write CSS vars on the pet root (e.g.
    `--aurora-gaze-x/y` in -1..1), throttled with `requestAnimationFrame`; PET_CSS uses them to offset pupils.
    Do not re-render React on every move.
  - Hotkey: `Ctrl+Shift+A` toggles `pet.enabled` (ignore when the event target is an input/textarea/
    select or contentEditable). Register on `window` in a `useEffect`, remove on cleanup.
  - `opacity: settings.pet.opacity` on the root; size passed to `PetArt`; accent from settings.theme.accent.
  - All copy is bilingual via `RUNTIME.getLocale()`; define your strings inside this fragment.
  - Never touch `document.body` / other plugins' DOM. Your own listeners + refs only; clean up everything.
